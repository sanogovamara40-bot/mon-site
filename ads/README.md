# Unanime — publicités 15 s

Trois formats, mêmes visuels et même montage, pour publication directe.

| Fichier | Format | Dimensions | Usage |
| --- | --- | --- | --- |
| `unanime-9x16.mp4` | 9:16 | 1080 × 1920 | Reels, TikTok, Shorts |
| `unanime-1x1.mp4` | 1:1 | 1080 × 1080 | Fil d'actualité |
| `unanime-16x9.mp4` | 16:9 | 1920 × 1080 | YouTube, LinkedIn, site |

Caractéristiques : H.264 High, 30 fps, `yuv420p`, faststart, 15,0 s, **sans audio**.
Les visuels d'arrivée sont dans `posters/`.

## Déroulé

1. **0–3,4 s** — « La réunion qui tombe juste. » Trois personnes, trois villes.
2. **3,4–7,4 s** — « Une seule réunion. Trois réalités. » 9h Paris, 8h Londres, 3h New York.
3. **7,4–12 s** — Démo : la grille superpose les horaires et met en évidence le
   recouvrement 15h–18h.
4. **12–15 s** — Carton final : Unanime, « Planifiez sans calcul mental. »,
   « Gratuit · Sans compte · 100 % local ».

## Note

Les vidéos sont muettes : pas de voix off ni de musique sous licence. Ajoutez une
piste audio dans l'éditeur de la plateforme si besoin.

Le montage est généré depuis `ad.html` (hors dépôt) via un rendu image par image
puis ffmpeg.
